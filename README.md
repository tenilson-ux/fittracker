# 🎯 FitTracker - Aplicativo de Acompanhamento de Emagrecimento

## 📋 Descrição

FitTracker é um aplicativo completo para acompanhamento de emagrecimento e saúde, permitindo registrar peso, alimentação, exercícios e consumo de água.

## ✨ Funcionalidades

### 👤 Perfil
- Cadastro completo de informações pessoais
- Cálculo automático de TMB (Taxa Metabólica Basal)
- Cálculo de TDEE (Gasto Calórico Total)
- Definição de metas calóricas personalizadas
- Distribuição de macronutrientes

### ⚖️ Controle de Peso
- Registro de pesagens
- Gráfico de evolução
- Cálculo automático de IMC
- Histórico completo

### 🍽️ Alimentação
- Registro de refeições por tipo
- Contagem de calorias e macronutrientes
- Resumo nutricional diário
- Acompanhamento de metas

### 🏃 Exercícios
- Registro de atividades físicas
- Cálculo de calorias queimadas
- Gráficos semanais
- Estatísticas de frequência

### 💧 Consumo de Água
- Registro visual de consumo
- Metas personalizáveis
- Gráficos de acompanhamento
- Lembretes visuais

### 📈 Progresso
- Dashboard completo
- Estatísticas gerais
- Gráficos de evolução
- Balanço calórico

## 🚀 Como Usar

1. **Instalação**
   - Faça download dos arquivos
   - Coloque todos os arquivos na mesma pasta
   - Abra o arquivo `index.html` no navegador

2. **Primeiro Acesso**
   - Vá até a aba "Perfil"
   - Preencha suas informações
   - Clique em "Salvar Perfil"

3. **Uso Diário**
   - Registre suas pesagens na aba "Peso"
   - Adicione suas refeições em "Alimentação"
   - Registre exercícios em "Exercícios"
   - Acompanhe água em "Água"
   - Veja seu progresso no "Dashboard"

## 💾 Armazenamento

Todos os dados são salvos localmente no navegador usando LocalStorage. Não há necessidade de servidor ou banco de dados externo.

## 📊 Cálculos Utilizados

- **IMC**: Peso / (Altura²)
- **TMB (Harris-Benedict)**:
  - Homens: 88.362 + (13.397 × peso) + (4.799 × altura) - (5.677 × idade)
  - Mulheres: 447.593 + (9.247 × peso) + (3.098 × altura) - (4.330 × idade)
- **TDEE**: TMB × Nível de Atividade
- **Meta Calórica**: TDEE ± 500 kcal (dependendo do objetivo)
